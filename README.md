# Kanban Board 📝
I created a kanban board with an object-oriented, responsive, and accessible design.
I utilized **functional components** to implement the task cards, **color inversion** to create a toggle between light mode and dark mode, and
**HTML5 web storage** to recall user inputs and customizations.  
  
Through this project, I explored:
* imperative programming using JavaScript, CSS, and HTML
* how to interact with the DOM via referencing elements and attaching event handlers
* use Chrome Dev Tools to debug and test the cascading nature of CSS styles and JS-supported user interaction
